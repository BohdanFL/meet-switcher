# Архітектурний аудит проєкту (ESLint Complexity)

Дата проведення: 20 Вересня 2026
Інструмент: ESLint v9 + typescript-eslint (правила `complexity`, `max-lines-per-function`, `max-lines`, `max-depth`)

## Загальний стан
Проєкт має 129 попереджень щодо складності коду. Більшість проблем сконцентрована у 4 файлах, які стали "точками скупчення" логіки. Архітектура не має циклічних залежностей, але страждає від перевантажених функцій (Божественні об'єкти/функції).

## Найкритичніші модулі для рефакторингу

### 1. `src/popup/popup.ts`
* **Проблема:** Файл-моноліт на **1000 рядків**. Вся логіка UI, управління станом та робота з даними знаходяться в одному місці.
* **Критичні функції:**
  * `renderRosterList` (222 рядки)
  * `initRoster` (190 рядків)
* **Архітектурні запахи:** Глибока вкладеність (Callback hell), змішування логіки відображення (DOM) з бізнес-логікою.
* **Рекомендація:** Розбити на `popup-ui.ts`, `popup-state.ts`, `popup-diagnostics.ts`.

### 2. `src/lms/parser.ts`
* **Проблема:** Величезна цикломатична складність.
* **Критичні функції:**
  * `parseLmsGroupPage` — **Складність 77** (норма до 15), 135 рядків, вкладеність рівня 5.
* **Архітектурні запахи:** Функція намагається розпарсити всю HTML сторінку за один прохід великою кількістю умов `if/else/for`.
* **Рекомендація:** Розбити на дрібні чисті функції: `extractGroupName()`, `parseStudentRows()`, `filterInactive()`.

### 3. `src/content/pin-controller.ts`
* **Проблема:** Перевантажені методи управління станом екрану.
* **Критичні функції:**
  * `switchToShare` — Складність 41, 137 рядків.
  * `pinViaPeoplePanel` — Складність 42.
* **Рекомендація:** Виділити логіку взаємодії з DOM (Meet UI Helpers) в окремий клас/модуль, залишивши в контролері лише координацію дій.

### 4. `src/content/ui/wall.ts`
* **Проблема:** Генерація складного HTML в коді.
* **Критичні функції:**
  * `render` — 222 рядки, складність 54.

## Наступні кроки
1. Налаштувати постійний контроль складності в CI/CD (через `npm run lint`).
2. Почати поступовий рефакторинг з `popup.ts` (найбільший вплив на підтримку).
3. Використовувати сабагентів для ізольованого рефакторингу цих файлів.
